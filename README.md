# godot-model-demo

Godot 4 里加载 3D 模型的最小可跑示例：`main.tscn` + `main.gd`，附 `shot.png` 运行截图。

## 运行

需要 [Godot 4.x](https://godotengine.org/download/windows/)（免费，单文件 exe，不用安装）。把本目录作为项目导入，或命令行：

```bash
godot --path .
```

`.godot/` 是导入缓存，已在 `.gitignore` 里排除，首次打开会重新生成。
